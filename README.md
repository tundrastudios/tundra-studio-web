# Tundra Studio · página web

Sitio estático de Tundra Studio (español en la raíz, inglés en `en/`).

- Las páginas se generan con `python3 tools/build.py` y `python3 tools/build_en.py`.
- Estilos en `styles.css`; miniaturas del portafolio en `assets/`.
- Se publica tal cual (sin paso de compilación) en Netlify o Vercel.
